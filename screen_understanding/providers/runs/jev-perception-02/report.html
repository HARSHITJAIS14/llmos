Limits

The narrative uses a fixed vocabulary and templates; it is not generated prose or a verbatim transcription. Jev receives only pixels, numeric boxes and neutral IDs, not prior icon captions, OCR text or known answers. Region presence threshold 0.5 is provisional. Confidence is not calibrated on these screens. Parent attachment also requires at least 50% box overlap; rejected relationships remain visible as issues. Detector time is a prior GPU measurement, not included in measured replay time. Capture and remote detector transfer are not measured.

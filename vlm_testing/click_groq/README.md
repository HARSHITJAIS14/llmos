# Click Groq: High-Speed VLM Execution Module

This directory contains the testing sandbox for the **Phase 2: Raw Coordinate Prediction** module. It serves as a high-speed, sub-2-second perception-to-click orchestrator utilizing the Groq LPU API and native macOS binaries.

## Architecture

This module bridges the physical macOS UI (via `agent-desktop` and Quartz) with a high-speed Vision-Language Model (VLM). The execution pipeline works as follows:

1. **Window Isolation**: Uses `agent-desktop` to locate the exact spatial bounds of a target macOS application.
2. **Perception**: Uses native macOS `screencapture` to pull an isolated retina screenshot of the window in ~130ms.
3. **Reasoning**: Downscales the image and ships it to Groq (`qwen3.8-27b`) to guess semantic X,Y coordinates based on natural language instructions.
4. **Execution**: Maps the predicted coordinates back to logical retina screen space and fires a hardware click using a custom Swift binary.

## Files Documented

### 1. `clicker.py`
The primary python orchestrator module. 
- **Purpose**: Defines the `GroqClicker` class which manages the end-to-end loop (Screenshot -> Groq API -> Click Execution).
- **Key Functions**:
  - `_get_window_screenshot()`: Interacts with `agent-desktop-darwin-arm64` to list windows, then invokes `screencapture -l` to pull the fastest possible retina screenshot of the isolated app window.
  - `click()`: The main entry point. Captures the image, encodes it, fires the Groq API payload, handles retina-to-logical coordinate math, saves a visual debug artifact (`click_result.jpg`), and ultimately executes the physical mouse click.
  - `_log()`: A helper function ensuring that every execution step and its latency in milliseconds is securely written to `../logs/clicker_YYYYMMDD_HHMMSS.log`.

### 2. `stealth_click.swift`
A custom macOS Swift script that executes physical hardware clicks.
- **Purpose**: Circumvents the limitations of `pyautogui` and `agent-desktop click` by providing a perfectly invisible "teleportation" click.
- **Mechanics**: It reads the user's current cursor position, uses `CGWarpMouseCursorPosition` to instantly teleport the cursor to the target, fires the `leftMouseDown` and `leftMouseUp` CGEvents, and instantly warps the cursor back. This prevents the agent from hijacking the user's physical mouse pointer during background tasks.

### 3. `stealth_click`
The compiled binary executable of `stealth_click.swift`.

### 4. `app_screenshot_raw.png`
A temporary runtime artifact representing the exact cropped retina screenshot of the isolated application window before it is downscaled and sent to Groq.

### 5. `click_result.jpg`
A runtime visual debugging artifact generated by `clicker.py`. It overlays a large red target reticle on the downscaled image at the exact coordinates predicted by the VLM. Useful for verifying accuracy when clicks fail.

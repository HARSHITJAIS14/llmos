## VLC (org.videolan.vlc) · appkit
Quirk thumbnail_proxy_window: pick window by title, take bounds from AX root
Quirk hidden_window_offscreen: read as trusted; activate and re-snapshot before any coordinate action
Quirk disabled_keeps_click: check disabled state before pressing
Quirk window_id_drift: re-pick window by title each session
Its window is often hidden: the executor activates it before typing or pointer clicks.
